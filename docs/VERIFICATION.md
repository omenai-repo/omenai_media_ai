### Email + password HTTP smoke (2026-10-15, `next dev` on :3123)

1. `/invite/<valid>` renders the password form for `founder@omenai.example`.
2. Accept with a short password → 400, and the invitation stays usable.
3. Accept with a valid password → 200 and `Set-Cookie: better-auth.session_token=…; HttpOnly; SameSite=lax` (set by the nextCookies plugin).
4. `GET /` with that session → 200, showing "Ada Founder", the owner role and the empty newsroom.
5. Reusing the invitation → 410 `INVITATION_ACCEPTED`.
6. Public `POST /api/auth/sign-up/email` without an invite → 403 `INVITATION_REQUIRED`.
7. Sign-out → 200, then `/` redirects to `/login`. Sign-in with the right password → 200. Wrong password → 401 `INVALID_EMAIL_OR_PASSWORD`.
8. `/login` renders the email and password form.
